# Spatial Proteomics Analysis

This project explores mass spectrometry–based spatial proteomics data to investigate protein abundance and subcellular localization.

The project uses the HyperLOPIT dataset and was completed as part of a bioinformatics course.

## Analysis

- **Spatial mapping:** Visualizes proteins based on their known subcellular localization
- **Dataset comparison:** Compares spatial maps and protein localization profiles across HyperLOPIT datasets
- **PCA:** Uses a scree plot to examine the principal components of the data
- **Location analysis:** Examines relationships between different subcellular compartments
- **Clustering:** Creates a dendrogram showing relationships between subcellular locations
- **Protein abundance:** Visualizes protein abundance across the dataset using a heatmap

The analysis was performed using the `pRoloc` framework in R, which provides tools for analyzing and visualizing spatial proteomics data.

## Tools
